## Core rules
- Team of 1 or 2 max (not 3). Unregistered team is fine.
- Pick exactly ONE of the 5 problem statements. No old ideas/projects. Going beyond the expected solution is welcome.
- Build by voice: dictate prompts, specs and fixes via Wispr Flow into any builder (Claude Code, Antigravity (free), Cursor, Lovable, Bolt, Replit). Don't type.
- Product's main input must be natural speech via Wispr Flow; agent must turn messy speech (fillers, digressions, self-corrections) into clean structured output.
- Wispr Flow is Mac/Windows only (no Ubuntu/Linux). Wispr is used on top of whatever model you use.
- Wispr account email must match the theproductspace.in registration email.
- Project must be deployed so judges can use it; give test credentials if there's a login (you can change them after ~a week).
- Video/submission is English is fine. Data stays internal to Product Space.
