# The 5 problem statements (pick one)
Applies to all: (1) build it by voice via Wispr Flow into your AI builder; (2) make it work with voice — main input is natural speech via Wispr; agent turns fillers/digressions/self-corrections into clear structured output.

## 01 Media: content repurposing studio with brand memory
Must build: long video/podcast ingestion; clip selection with reasons per choice; captions + copy tailored per platform; brand-voice memory that learns from the creator's edits; content calendar; performance feedback loop that changes future suggestions based on what actually performed.

## 02 Adaptive exam-prep tutor with a learner model
Generic tutors don't track what a student actually understands. Must build: diagnostic test; concept graph for one syllabus (e.g. Class 10 physics); learner model updating mastery per concept after every answer; question generation targeted at weak concepts with difficulty calibration; misconception detection from the reasoning in wrong answers (not just the final answer); spaced-repetition scheduling; teacher dashboard of class-wide gaps.

## 03 Meeting-to-execution agent
Decisions made in meetings get lost. Must build: transcript ingestion with speaker attribution; extraction of decisions, action items, owners, deadlines; detection of conflicts with earlier decisions stored in memory; task creation in a tracker via an integration; reminders before deadlines; weekly digest per person; confirmation step before anything is posted. Cross-meeting memory + conflict detection are what make it a system, not a summarizer.

## 04 Personal finance coach with a living money model
Budget apps categorize and stop. Must build: ingestion of messy bank statements (PDF, CSV, transaction SMS) with auto-categorization; correction loop that learns a rule from a user fix; recurring payment/subscription detection with alerts when one changes or goes unused; persistent financial profile (income, fixed costs, emergency fund, goals with target dates); goal planner with what-if simulation ("cut dining 30%", "rent goes up"); nudges when spending drifts; monthly review report; guardrails — educates and models scenarios, never recommends specific securities.

## 05 Career pivot coach
Must build: resume + target-role intake; skill-gap map from real job descriptions; week-by-week learning plan; portfolio project suggestions matched to gaps; mock interviews scored against a rubric; progress tracking that adjusts the plan; application tracker that learns which kinds of roles get responses.
